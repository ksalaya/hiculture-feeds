HiCulture Feeds

Data files for the HiCulture page at kylesalaya.com/hiculture. A GitHub Action refreshes them every night, because browsers can't read most RSS feeds or court websites directly.

  • feed.json: the latest articles from about 150 cultural, science, law and medicine feeds
  • law-library.json: California law updates, jury instruction documents, statutes and Rules of Court
  • status.json and law-status.json: what the last run fetched and which sources failed
